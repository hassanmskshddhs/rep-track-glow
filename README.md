# Iron Log

​"I want to build a fitness tracking web app. The app should have 4 main workout cards based on my routine: Push, Pull, Legs+Abs, and Upper.

​Key Features:

​Each workout day displays a list of exercises (I will provide the list).

​For each exercise, I need input fields for 'Weight' and 'Reps'.

​A 'Log Workout' button that saves the session with a timestamp.

​A 'History' tab to see my previous weights so I can track progressive overload.

​Use a clean, dark-mode 'Gym Aesthetic' UI with shadcn/ui components and Tailwind CSS."
